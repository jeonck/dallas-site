어른을 위한 무료 영어 — 도서관마다, 카운티마다 다른 곳을 봅니다

캐롤튼·플레이노·프리스코·어빙 공공도서관은 저마다 다른 방식으로 성인 영어를 지원합니다 — 직접 강좌를 여는 곳도 있고, ISD 나 커뮤니티 칼리지로 안내만 하는 곳도 있습니다. 달라스 카운티 거주자는 Dallas College WorkReadyU, 콜린 카운티 거주자는 Collin College AEL 이 무료 성인 ESL 의 큰 축입니다.

최종 확인 2026년 9월 23일

목차
  • 두 종류가 있습니다
  • 도서관은 도시마다 방식이 다릅니다

두 종류가 있습니다

어학원에 돈을 쓰기 전에 확인할 것이 있습니다. 무료 영어 프로그램은 도서관의 회화 모임과 주(TWC) 지원을 받는 정규 성인교육(AEL) 두 갈래로 있고, 성격이 완전히 다릅니다.

회화 모임 정규 ESL 수업(AEL)
형식 앉아서 대화, 격식 없음 레벨별 수업, 진도가 있음
등록 대개 필요 없음 등록·서류 심사·레벨 테스트
시작 시점 아무 때나 상시 등록이거나 학기 단위
비용 무료 무료(자격 요건 있음)

도착한 지 얼마 안 됐으면 회화 모임부터 가세요. 등록도 서류도 필요 없습니다. 정규 수업은 서류 준비가 끝나는 대로 신청하면 됩니다.

도서관은 도시마다 방식이 다릅니다

같은 "공공도서관 ESL" 이라도 캐롤튼·플레이노·프리스코·어빙은 운영 방식이 다릅니다.

캐롤튼 — 직접 열지 않고 지역 목록을 정리합니다

캐롤튼 공공도서관은 자체 ESL 강좌 대신, 사서가 정리한 지역 무료·유료 ESL·GED 기관 목록을 PDF 로 올려 둡니다(2025-05 갱신, 2026-09 확인 시 여전히 게시 중). 캐롤튼과 가까운 항목은 다음과 같습니다.

  • Farmers Branch Manske Library — 월·목 18:30, 무료, 등록 불필요. 주소 13613 Webb Chapel Rd, Farmers Branch.
  • Dallas College Brookhaven 캠퍼스(WorkReadyU) — 3939 Valley View Ln, Farmers Branch. 아래 Dallas College 절 참고.
  • Denton ISD AEL — 데는·콜린 카운티 거주자 대상 무료 ESL·HSE, 등록 필요. 목록에는 940-369-0400 / aelcontact@dentonisd.org 로 안내돼 있습니다. 이 문서에서는 Denton ISD 자체 페이지를 직접 확인하지 못했으니, 신청 전 전화로 재확인하세요.

플레이노 — 도서관이 직접 두 프로그램을 운영합니다

Plano Public Library 는 Conversational English(매주, 회화 연습, 등록 불필요)와 ESL 수업(레벨별로 말하기·읽기·쓰기 기초를 가르치는 무료 강좌) 두 가지를 자체 운영합니다 (2026-09 확인). 일정은 고정돼 있지 않고 도서관 온라인 캘린더에 올라오므로, 가기 전에 일정 캘린더에서 그 주에 열리는지 확인하세요.

프리스코 — ESL Language Lab 과 ESL Chat

Frisco Public Library 는 두 가지를 정기 운영합니다(2026-09 확인).

프로그램 시간 성격
ESL Language Lab 매주 일요일 18:00–20:00 초·중·고급 학습 자료·영상으로 자습형 학습
ESL Chat 매주 월요일 10:30–11:30 회화 연습
Advanced ESL Book Club 격주(2주 간격) 토요일 14:00–15:00 고급 학습자 대상 독서 모임

모두 무료이며 Frisco Library 한 곳에서 열립니다. 최신 날짜는 도서관 ESL 페이지에서 확인하세요.

어빙 — 도서관 대신 Irving ISD 가 운영합니다

Irving Public Library 는 자체 ESL 수업을 열지 않고, Irving ISD Adult Education and Literacy(AEL) 가 도서관 여러 지점에서 여는 수업으로 안내합니다(2026-09 확인). 도서관은 대신 ESL 학습용 DVD·도서, Mango Languages 같은 온라인 학습 도구를 제공합니다.

Irving ISD AEL 은 이민자·이주 노동자를 포함해 영어가 모국어가 아닌 성인이면 누구나 대상이고, 자국에서 학위·자격증을 가진 전문직도 포함한다고 명시합니다(2026-09 확인). 하루 중 여러 시간대에 수업이 열리며 지점에 따라 다릅니다.

  • 등록 페이지: Register Today
  • 문의: 972-600-6130

Dallas College WorkReadyU — 달라스 카운티 거주자 대상

Dallas College 의 WorkReadyU ESL Academy 는 Austin ISD AEL 처럼 카운티 단위의 무료 성인 ESL 입니다(2026-09 확인). 듣기·말하기·읽기·쓰기 네 영역을 소규모 반에서 배우고, 상시 등록을 받습니다.

자격 요건(2026-09 확인)

  • 사진이 있는 신분증
  • 달라스 카운티 거주(어빙, 캐롤튼 남부 등)
  • 아직 학사 학위를 취득하지 않았을 것

등록은 3단계입니다 — ① 관심 등록서(interest form) 작성 → ② 서류 요건 완료 → ③ 배정 코치 (CCL Coach)와 상담해 반·일정 결정. 캠퍼스는 Brookhaven(3939 Valley View Ln, Farmers Branch)이 캐롤튼과 가장 가깝고, 이 외에 Eastfield·El Centro·Mountain View·North Lake·Richland·Cedar Valley 에서도 엽니다.

Collin College AEL — 콜린 카운티 거주자 대상, 비자 조건 확인 필수

Collin College 의 Adult Education and Literacy(AEL) 는 만 19세 이상 성인에게 읽기·쓰기· 수학·ESL·GED 를 무료로 제공하는 텍사스 워크포스 커미션(TWC) 프로그램입니다(2026-09 확인). 플레이노 Spring Creek 캠퍼스(2800 E Spring Creek Pkwy, Suite J112)가 접수처입니다.

등록에는 신분증이 필요하고, 받아주는 서류와 받아주지 않는 서류가 정해져 있습니다(2026-09 확인).

  • 인정 — 미국 여권, 주 발급 운전면허증/신분증(임시 면허 제외), 영주권(그린카드), 취업허가서 (EAD), 사회보장카드(추가 서류와 함께)
  • 불인정 — 임시(limited-term) 운전면허증, 외국 여권, F-1·J-1·H-4·B-1/B-2·배우자(L-2)· K-1 비자 서류, 외국 영사관 발급 신분증

주재원 배우자나 유학생 가족이라면 이 비자 조건에 걸릴 가능성이 큽니다. 워크인(walk-in) 등록은 받지 않으므로 전화·이메일로 먼저 대기자 명단에 오른 뒤 오리엔테이션 일정을 받습니다. 만 19세 미만은 별도 문의가 필요합니다.

무엇부터 할까

  1. 이번 주에 바로 — 사는 도시의 도서관 회화 모임(플레이노 Conversational English, 프리스코 ESL Chat, 캐롤튼 인근 Farmers Branch Manske Library)에 등록 없이 갑니다
  2. 달라스 카운티(어빙·캐롤튼 남부) — Dallas College WorkReadyU 관심 등록서를 작성합니다. 학사 학위가 없어야 하는 조건을 확인하세요
  3. 콜린 카운티(플레이노·프리스코) — Collin College AEL 에 전화·이메일로 문의합니다. 비자 신분이 F-1·J-1·H-4·B-1/B-2·L-2·K-1 이면 등록이 안 되니 먼저 확인하세요
  4. 데는 카운티 쪽 캐롤튼 — Denton ISD AEL 에 전화로 등록 여부를 확인합니다
  5. 자녀가 어빙 ISD 에 다니면 — Irving ISD AEL 수업이 다니는 학교 근처 도서관에서 열리는지 확인합니다

돈을 내는 어학원은 이 다섯을 다 해 보고 나서 생각해도 늦지 않습니다. 각 기관 페이지가 이 문서보다 정확합니다.
